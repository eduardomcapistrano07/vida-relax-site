# Site da Vida Relax Poltronas

Código do site vidarelaxpoltronas.com.br, publicado pelo Netlify.

- `main` é o que está no ar. Todo commit em `main` publica o site automaticamente.
- Páginas e artigos novos são feitos em um branch separado, com um pull request. O Netlify gera um link de prévia para cada pull request. Depois de aprovado, o pull request é mesclado em `main` e vai para o ar.
- Site estático (HTML, CSS e JS), sem etapa de build.
